# 🏙️ Neo City 3D (摩天都市 3D：生态沙盒 & 吊装盖楼)

基于 **Three.js (WebGL)** 打造的 3D 城市生态模拟与 **Tower Bloxx 3D 吊装盖楼** 综合游戏！无需任何构建工具，打开网页即可畅玩并分享。

🌐 **在线预览体验 (GitHub Pages)**：👉 **[https://tcdd19.github.io/neo-city-3d/](https://tcdd19.github.io/neo-city-3d/)**

## ✨ 核心特性

1. **🏢 多样化 3D 城市建筑与自由沙盒规划**
   - 内置 **超高层玻璃幕墙摩天大楼**、**经典湖蓝金顶住宅公寓**、**赛博霓虹商业综合体** 以及 **中央音乐喷泉生态公园**。
   - 支持自由点击城市地块进行新建、改建或拆除，实时统计城市总人口与绿化指标。
2. **🏗️ 3D Tower Bloxx 摩天吊装盖楼挑战**
   - 在鲜活的 3D 城市街区中启动高空摇摆吊钩，按下 `空格键` 或点击屏幕释放标准层。
   - 支持 **PERFECT 完美对齐连击加成**、高层建筑微幅物理摇晃，并在封顶时自动加冕经典红尖顶与金旗！
3. **🚗 智能 3D 车流系统**
   - 包含新能源轿车、GT 超跑、城市出租车、智慧观光巴士与物流货车。
   - 支持十字路口自动转向、车轮滚动动画，以及夜间/雨雾天气自动开启立体车灯束与尾灯。
4. **🚶 鲜活街头行人与雨伞交互**
   - 3D 行人沿人行道自然摆臂行走；当切换至 **倾盆大雨** 或 **漫天飞雪** 天气时，行人会自动撑起彩色雨伞！
5. **🌳 丰富植物与自然景观**
   - 涵盖阔叶橡树、粉色樱花树、苍翠松柏、开花灌木丛与动态喷泉，树冠随微风或暴风雨自然摇曳。
6. **🌦️ 6 大实时天气与昼夜光影切换**
   - 一键切换：**☀️ 晴朗白昼**、**🌇 黄昏落日**、**🌃 璀璨夜景**、**🌧️ 倾盆大雨（含闪电惊雷）**、**❄️ 漫天飞雪**、**🌫️ 迷雾晨曦**。
7. **🎥 4 种沉浸式镜头模式**
   - 支持 **🦅 自由鸟瞰**、**🚁 航拍环游**、**🚘 跟随车辆视角**、**🚶 跟随行人漫步视角**。

## 🎮 操作指南

| 功能 | 操作方式 |
| :--- | :--- |
| **旋转 / 缩放 / 平移视角** | 鼠标左键拖拽旋转 / 滚轮缩放 / 右键拖拽平移（移动端支持单指旋转、双指缩放） |
| **切换天气效果** | 点击右侧面板【实时天气与光影】中的 6 种天气按钮 |
| **切换跟随视角** | 点击右侧面板【视角漫游切换】，或直接点击街上的汽车/行人并选择【锁定跟随】 |
| **3D 吊装盖楼 (Tower Bloxx)** | 点击底部工具栏【🏗️ 3D 吊装盖楼】，按 `Space (空格)` 或点击屏幕释放楼层 |
| **自由建造建筑与植物** | 选择底部【建摩天楼 / 建公寓楼 / 建商业街 / 种植物公园 / 清理地块】后点击任意地块 |
